# DEMO Property Management

A responsive company website demo for DEMO, a thoughtful property-management company.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory.

## Deployment

This is a static site designed for GitHub Pages. It uses the repository root as its Pages source.

The repository is intentionally private. GitHub Pages for private repositories requires a
GitHub Pro, Team, or Enterprise plan. After the owning account has an eligible plan, enable
Pages once in the repository's Settings → Pages with **GitHub Actions** as the source; the
existing `Deploy DEMO website` workflow will then publish the site on pushes to `main`.
